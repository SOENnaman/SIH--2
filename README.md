# Niyamit Frontend — Hackathon Starter

This is a React + Vite frontend closely recreated from the supplied Niyamit reference image.

## Run

1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Routes

- `/home` — Landing page
- `/login` — Login
- `/` — Dashboard
- `/inspection` — New inspection / upload
- `/inspection/results` — Inspection result
- `/reports` — Reports
- `/products` — Product repository
- `/analytics` — Analytics
- `/users` — User management placeholder
- `/settings` — Settings placeholder

The frontend currently uses mock data. The upload flow simulates analysis and routes to the result screen. Replace the mock data/API calls with your team's backend when it is ready.
